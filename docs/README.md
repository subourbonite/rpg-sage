## Quick Reference

### Core Command Patterns
- **Text Commands**: `sage! <command> <args>`
- **Slash Commands**: `/sage-<command> <args>`
- **Dice Rolling**: `[dice notation]` or `[[dice notation]]` (inline)

### Supported Game Systems
- Pathfinder 1st Edition (PF1E)
- Pathfinder 2nd Edition (PF2E)
- Starfinder 1st Edition (SF1E)
- Starfinder 2nd Edition (SF2E)
- D&D 5th Edition (DND5E)
- Essence20 (E20)

### Key Features
- Advanced dice rolling with many modifiers and options
- Character sheet integration (Pathbuilder, PDF import)
- Macro system for complex dice expressions
- Game and server management tools
- Content search for supported game systems
- Map management and token placement
- Weather generation and calendar tracking
